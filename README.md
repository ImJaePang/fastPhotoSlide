# 📸 PhotoViewer (안드로이드 디지털 액자 & 자동 슬라이드쇼 뷰어)

React Native 및 Expo 기반으로 제작된 안드로이드용 **자동 사진/동영상 슬라이드쇼 뷰어(디지털 액자)** 앱입니다.  
태블릿이나 스마트폰을 거치해 두고 앨범 내의 미디어를 감상할 수 있도록 최적화되어 있습니다.

---

## ✨ 주요 기능

- **자동 슬라이드쇼**: 기기의 특정 사진 앨범을 선택하여 정해진 시간 간격으로 미디어를 자동 전환합니다.
- **화면 꺼짐 방지 (`KeepAwake`)**: 앱 실행 중 화면이 꺼지지 않고 액자 형태로 계속 유지됩니다.
- **다양한 화면 전환 효과 (Transition Effects)**:
  - **None** (효과 없음)
  - **Fade** (부드러운 페이드 인/아웃)
  - **Slide** (좌우 슬라이드)
  - **Zoom** (확대 전환)
  - 단일 효과 지정 또는 다중 효과 랜덤 전환 모드 지원
- **스마트 세로 사진 스크롤**:
  - 화면보다 긴 세로 사진의 경우, 잘리지 않고 위에서 아래로 부드럽게 스크롤되어 전체 내용을 감상할 수 있습니다.
- **스마트 비디오 재생**:
  - 동영상은 액자 환경에 맞게 **무음(Muted)으로 자동 재생**됩니다.
  - 영상 길이가 슬라이드 시간보다 짧으면 설정 시간 동안 루프 재생됩니다.
  - 영상 길이가 슬라이드 시간보다 길면 영상이 완전히 끝날 때까지 대기한 후 다음 슬라이드로 넘어갑니다.
- **shadcn 스타일 UI & 테마**:
  - 시스템 / 라이트 / 다크 모드 지원 (시스템 설정을 따라감)
  - 포인트 컬러 6종 (Zinc, Blue, Green, Rose, Orange, Violet) 선택 가능
- **마지막 앨범 자동 재생**: 앱을 다시 켜면 마지막으로 보던 앨범과 설정(간격, 테마, 전환 효과)이 복원됩니다.
- **장시간 구동 안정성**:
  - 더블 버퍼 방식 전환으로 이미지 레이어가 쌓이지 않고, 전환이 끝나면 이전 레이어를 즉시 해제합니다.
  - 디코딩 크기 상한(약 8MP), 로드 실패 시 자동 건너뛰기, 렌더링 오류 시 3초 후 자동 재시작.
- **장시간 구동 메모리 최적화**:
  - 대량의 사진을 연속 감상할 때 OOM(메모리 부족) 현상을 방지하기 위해 100장 교체 주기마다 메모리 캐시 정리(GC) 및 다음 미디어 사전 로드(Prefetch) 적용.

## 📁 지원 파일 확장자

기기 내 앨범에서 아래 확장자에 해당하는 미디어만 자동으로 필터링되어 재생됩니다.

| 구분 | 지원 확장자 |
| :--- | :--- |
| **이미지 (Photo)** | `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`, `.gif` (GIF 애니메이션 지원) |
| **동영상 (Video)** | `.mp4`, `.webm`, `.mov`, `.3gp` |

## 🎮 조작 및 사용 방법

- **앨범 선택**:
  - 앱 처음 실행 시 미디어 접근 권한을 허용하면 앨범 선택 창이 뜹니다. 재생하고자 하는 앨범을 선택합니다.
- **설정 창 열기**:
  - 화면 **중앙**을 탭하면 상단/하단에 설정 및 제어 오버레이가 나타납니다.
  - 설정 창은 터치가 없으면 **10초 후 자동으로 숨겨집니다**.
- **슬라이드 제어**:
  - **화면 왼쪽 탭**: 이전 사진/영상으로 이동
  - **화면 오른쪽 탭**: 다음 사진/영상으로 이동
  - **일시정지 / 재생**: 설정 오버레이의 재생/일시정지 버튼으로 자동 슬라이드를 멈추거나 다시 시작할 수 있습니다.
- **설정 항목**:
  - 슬라이드 전환 시간 조절 (기본: 10초)
  - 전환 애니메이션 종류 및 전환 소요 시간 조절
  - 앨범 변경
  - 테마(시스템/라이트/다크) 및 포인트 컬러

## 🛠️ 개발 및 빌드 환경

- **Framework**: React Native (0.83.2) / Expo SDK 55
- **애니메이션 & 제스처**: React Native Reanimated (4.2.1), React Native Gesture Handler
- **미디어 라이브러리**: `expo-media-library`, `expo-image`, `expo-video`

### 실행 방법

```bash
# 1. 의존성 패키지 설치
npm install

# 2. Expo 개발 서버 실행
npx expo start

# 3. 안드로이드 기기 또는 에뮬레이터에서 실행
npm run android
```

### 설치 파일
- 빌드된 APK는 저장소에 포함하지 않고 [GitHub Releases](https://github.com/ImJaePang/fastPhotoSlide/releases)에서 배포합니다.
- 최신 릴리스의 `photoViewer.apk`를 안드로이드 기기에 내려받아 설치하세요. (출처를 알 수 없는 앱 설치 허용 필요)
- 직접 빌드하려면 (`android/` 폴더는 생성물이라 저장소에 없으므로 먼저 생성합니다):

```bash
npm install
npx expo prebuild --platform android
cd android
./gradlew assembleRelease   # 결과물: android/app/build/outputs/apk/release/app-release.apk
```
- 릴리스 배포 절차는 [RELEASING.md](./RELEASING.md)를 참고하세요.
